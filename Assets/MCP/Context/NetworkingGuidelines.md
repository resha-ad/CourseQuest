# Networking Guidelines — CourseQuest VR

**Not applicable.** CourseQuest VR has no real-time multiplayer or peer networking. The only network
activity is Unity Gaming Services **Cloud Save** (anonymous-auth, asynchronous save/leaderboard
persistence) — see `Architecture.md`. This file (and `NetworkingCSP.md`) can be deleted if you'd
rather not carry them; kept for now since the template's own convention treats their absence as "safe
to delete," not "must delete."
